# AWS Widgets context

## Product signals

- **Descriptor-icon traffic**: Requests for `logo192.png`, the icon declared for
  the AWS Widget Connect macro. In the measured seven-day period, identified
  active customer sites reached only this descriptor asset.
- **Observed product use**: No macro renderer, editor, or AWS resource-call
  traffic was observed in that period.
- **Prioritization status**: Treat current AWS Widget usage as inactive when
  prioritizing work. This is an operational decision based on the measured
  traffic; it is not proof that underlying market demand is zero.

## Relationship

Descriptor-icon traffic shows Confluence loaded AWS Widget metadata. It does
not establish that a customer rendered, edited, or successfully used an AWS
resource widget.
